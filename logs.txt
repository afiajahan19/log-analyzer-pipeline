## **1. Automated Log Analyzer Pipeline using Jenkins**

### 🔹 Task 1: GitHub Setup

Create a repository in GitHub named:

```
log-analyzer-pipeline/
│── logs.txt
│── analyzer.py
│── Jenkinsfile
```

Upload all required files into the repository.

---

### 🔹 Task 2: Python Script (Log Analyzer)

Using Python, create `analyzer.py`:

```python
log_file = "logs.txt"

info = 0
error = 0
warning = 0

with open(log_file, "r") as file:
    for line in file:
        if "INFO" in line:
            info += 1
        elif "ERROR" in line:
            error += 1
        elif "WARNING" in line:
            warning += 1

with open("report.txt", "w") as report:
    report.write("Log Summary Report\n")
    report.write("-------------------\n")
    report.write(f"INFO: {info}\n")
    report.write(f"ERROR: {error}\n")
    report.write(f"WARNING: {warning}\n")

print("Report Generated Successfully!")
```

---

### 🔹 Task 3: Jenkins Pipeline

Create a `Jenkinsfile` using Jenkins:

```groovy
pipeline {
    agent any

    stages {
        stage('Clone Repository') {
            steps {
                git 'https://github.com/your-username/log-analyzer-pipeline.git'
            }
        }

        stage('Run Python Script') {
            steps {
                sh 'python3 analyzer.py'
            }
        }

        stage('Archive Report') {
            steps {
                archiveArtifacts artifacts: 'report.txt', fingerprint: true
            }
        }
    }
}
```

---

### 🔹 Task 4: Automation

Enable automatic execution in Jenkins:
